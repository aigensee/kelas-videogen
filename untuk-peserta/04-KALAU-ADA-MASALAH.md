# Kalau ada masalah: pesan darurat siap salin

Salin kotak yang sesuai ke chat agen. Tidak perlu memahami errornya.

---

**AI berhenti di tengah jalan / tidak menjawab**

```
Lanjutkan pekerjaan terakhirmu. Kalau tadi ada yang gagal, jelaskan dalam
satu kalimat lalu perbaiki.
```

**Halaman localhost tidak bisa dibuka**

```
Halaman http://localhost:3000 tidak bisa dibuka di browserku. Cek apakah
aplikasinya sedang berjalan, nyalakan lagi bila perlu, lalu beri aku link
yang benar.
```

**Ada tulisan merah / error di layar atau di terminal**

```
Muncul error ini: <tempel errornya di sini>
Jelaskan artinya dengan bahasa sederhana, lalu perbaiki dan cek ulang.
```

**Tampilan berantakan setelah perubahan terakhir**

```
batalkan perubahan terakhir, kembalikan ke titik simpan sebelumnya
```

**AI memintaku mengetik kode atau mengedit file**

```
Ingat aturan di AGENTS.md: aku Bos dan tidak bisa ngoding. Tolong kamu yang
kerjakan semuanya. Pengecualian hanya mengisi kunci rahasia dan login.
```

**AI seperti lupa aturan / lupa proyeknya (chat baru atau chat terlalu panjang)**

```
Baca ulang AGENTS.md, terutama bagian Cerita Bos, Keputusan, dan Kemajuan.
Ringkas posisi proyek kita dalam 3 poin, lalu lanjutkan.
```

**Aku terlanjur menempel kunci API di chat**

```
Aku terlanjur menempel kunci API di chat. Pandu aku mencabutnya di yorai.id,
membuat kunci baru, dan mengisinya dengan aman. Jangan ulangi kunci lama
di jawabanmu.
```

**Kunci API sempat terlihat saat share screen**

```
Kunci API-ku sempat terlihat saat share screen di meeting. Pandu aku
mencabutnya di yorai.id, membuat kunci baru, lalu menggantinya di
.env.local dan di Vercel (kalau sudah online).
```

**Video gagal dibuat terus**

```
Video selalu gagal dibuat. Cek penyebabnya dari pesan error Yorai tanpa
membuat video baru dulu, jelaskan ke aku, lalu sarankan pengaturan yang
lebih aman (model, durasi, resolusi).
```

**Waktu tinggal sedikit dan aku masih tertinggal**

```
Mode kilat: waktu kelas tinggal sedikit. Selesaikan versi paling sederhana
yang bisa dipakai (composer, tombol Buat, kartu hasil, unduh), tunda sisanya
sebagai "Nanti" di AGENTS.md, lalu lanjut ke tahap berikutnya.
```
